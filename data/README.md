# Data files

The figure scripts expect the following local inputs, which can be downloaded from [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23780837.svg)](https://doi.org/10.5281/zenodo.23780837).

| File | Use |
| --- | --- |
| `simu_data.mat` | Simulated B1 and tissue data for Figure 2 |
| `VOPs.mat` | VOP matrices used by Figures 2–4 |
| `bcmask_Duke.mat` | Default optimization mask for Figure 2 |
| `bcmask_Ella.mat` | Optional Ella-model mask supported by Figure 2 |
| `meas_DXHB-3KQV.mat` | Measured maps and masks for Figure 3 |
| `universal_shim_datasets.mat` | Multi-subject inputs for Figure 4 |
